## 数据流

```
用户触发 / GitHub Actions Cron / WorkBuddy / Docker Ofelia / systemd timer
  │
  ├─→ fetch-news-ai.js (v4.0)
  │    │  1. Run lock 防重复（30 分钟 TTL）
  │    │  2. 串行抓取 uapis.cn 热榜（15 平台，300ms 间隔防 429）
  │    │  3. 并行抓取额外信息源（AIbase/AI-Bot/猫目/CNMO科技/IT之家/数码闲聊站/
  │    │      GitHub Trending/Product Hunt/Hacker News 共 9 源）
  │    │  4. 按版块关键词过滤热榜（10 版块各自匹配关键字）
  │    │  5. 分 2 批并行调用 AI（每组 ≤4 版块，批内串行），生成含 commentary 的新闻
  │    │  6. 调用 AI 生成头条(TOP3) + TL;DR + 5 趋势深度解读
  │    │  7. 抓取新浪股市 API（上证/深证/创业板/恒生，GBK 解码）
  │    │  8. 抓取 open-meteo 天气 API
  │    │  9. 完整性检查（GOOD≥40条 / DEGRADED 20-39 / LOW<20）
  │    │  10. AI 失败自动降级到纯热榜模式（fetch-cn-news.js）
  │    └─→ 输出: data/{period}-latest.json
  │
  ├─→ gen-html.js (v4.0)
  │    │  · 4 时段渐变头部（晨/午/傍晚/夜）
  │    │  · ⚡ TL;DR 金条速览（金色渐变背景）
  │    │  · 📈 股市指数深色容器（红涨绿跌）
  │    │  · 📋 双列紧凑目录导航（固定入口 + 双列版块网格）
  │    │  · 🔥 TOP 3 头条（带编号色标 + AI 编者按）
  │    │  · 📝 卡片分隔线（2px 边界感清晰）
  │    │  · 🕐 相对时间（刚刚/X分钟前/X小时前/X天前）
  │    │  · ⭐ 星级评分（★/☆ unicode）
  │    │  · 🧠 AI 深度解析（100% 覆盖，每条 100-200 字）
  │    │  · 💡 趋势深度解读卡片
  │    │  · 💬 每日一句
  │    └─→ 读取 JSON → 渲染响应式 HTML 邮件 → 输出: data/{period}-email.html
  │
  └─→ mail-provider.js
       └─→ 读取 HTML → SMTP/API 发送 → 配置的收件人邮箱
```

### 外部 API 调用量（单次运行）

| API | 调用次数 | 说明 |
|-----|---------|------|
| uapis.cn | 15次串行 | 热榜数据（300ms 间隔避免 429） |
| AIbase/AI-Bot/猫目/CNMO科技/IT之家 | 5次 | HTML 爬取（额外信息源） |
| GitHub/PH/HN/数码闲聊站 | 4次 | API/搜索 获取 |
| DeepSeek（或其他 AI） | 5次 | AI 生成（2批×2组版块 + 1次头条趋势） |
| 新浪财经 | 1次 | 股市指数（GBK 解码） |
| open-meteo | 1次 | 天气 |
| SMTP/API | 1次 | 发送邮件 |

## 核心脚本说明

### ai-provider.js

**职责**: 屏蔽不同 AI 提供商的 API 差异，提供统一 `.chat()` 接口。

**支持的协议**:
- **OpenAI 兼容** (默认): DeepSeek / MiniMax / OpenAI / 通义千问 / 智谱 / 豆包 / Kimi / Moonshot / 阶跃星辰 / 小米 Mimo / 快手可灵 / 腾讯混元 / 华为盘古 / 商汤 / 讯飞星火 / Groq / 硅基流动 / TokenHub / 阿里云百炼 / Custom
- **Anthropic 原生**: Claude Sonnet / Haiku / Opus
- **Google Gemini 原生**: Gemini 2.5 / 2.0
- **百度文心原生**: ERNIE 4.0

**环境变量**: `AI_PROVIDER` / `AI_API_KEY` / `AI_MODEL` / `AI_BASE_URL` / `AI_TIMEOUT` / `AI_MAX_TOKENS` / `AI_TEMP`

**CLI 命令**:

```bash
node scripts/ai-provider.js --list          # 列出 22+ 支持的提供商
node scripts/ai-provider.js --test "问题"    # 测试当前配置的 AI
node scripts/ai-provider.js --config        # 查看当前配置
```

**API 签名**:

```javascript
const ai = require('./ai-provider');

// 普通对话
const text = await ai.chat([
  { role: 'user', content: '你好' }
]);

// JSON 模式（自动去除 markdown 代码块标记）
const json = await ai.chatJSON([
  { role: 'user', content: '返回 JSON' }
]);

// 列出所有支持的提供商
const providers = ai.listProviders();

// 获取当前配置
const config = ai.getConfig();
```

### mail-provider.js

**职责**: 统一邮件发送层，支持 14+ 邮件服务商。

**支持的协议**:

**SMTP** (nodemailer):
- QQ 邮箱 (smtp.qq.com:465 SSL)
- 网易 163 (smtp.163.com:465 SSL)
- 网易 126 (smtp.126.com:465 SSL)
- 网易 yeah (smtp.yeah.net:465 SSL)
- Gmail (smtp.gmail.com:587 STARTTLS)
- Outlook/Hotmail (smtp-mail.outlook.com:587 STARTTLS)
- Yahoo (smtp.mail.yahoo.com:587 STARTTLS)
- 阿里云邮箱 (smtp.aliyun.com:465 SSL)
- QQ 企业邮箱 (smtp.exmail.qq.com:465 SSL)
- 自定义 SMTP

**HTTP API** (纯 REST，无需 SMTP 端口):
- Resend (https://api.resend.com/emails)
- SendGrid (https://api.sendgrid.com/v3/mail/send)
- Mailgun (https://api.mailgun.net/v3/{domain}/messages)
- Postmark (https://api.postmarkapp.com/email)
- Microsoft Graph (https://graph.microsoft.com/v1.0/me/sendMail)

**API 签名**:

```javascript
const mail = require('./mail-provider');

// 发送邮件
await mail.send({
  to: 'friend@qq.com',
  subject: '测试',
  html: '<h1>Hello</h1>',
});
```

**CLI 命令**:

```bash
node scripts/mail-provider.js --list                         # 列出 14+ 邮件服务
node scripts/mail-provider.js --test                         # 给自己发测试邮件
node scripts/mail-provider.js --config                       # 查看当前配置

```

**环境变量**: `MAIL_PROVIDER` / `MAIL_USER` / `MAIL_PASS` / `MAIL_FROM` / `MAIL_TO` / `MAIL_SMTP_HOST` / `MAIL_SMTP_PORT` / `MAIL_SMTP_SECURE` / `MAIL_API_KEY` / `MAILGUN_DOMAIN`

### fetch-news-ai.js

**职责**: 主流程编排——抓取数据 + 调用 AI + 降级 + 完整性检查。

**流程**:

1. **Run lock**: 30 分钟内同周期不重复运行（`data/.locks/` 目录）
2. **热榜抓取**: 串行调 15 个 uapis.cn 接口（300ms 间隔，避免 429 限流）
3. **额外信息源**: AIbase/AI-Bot/猫目/CNMO科技/IT之家（HTML 爬取）+ 数码闲聊站（百度搜索）+ GitHub Trending/Product Hunt/HN（API）
4. **关键词过滤**: 每个版块用 `SECTION_KEYWORDS` 匹配热榜，不足 2 条时取前 3 热榜兜底
5. **AI 生成**: 分 2 批并行（每批 2 组，每组 ≤4 版块），每条新闻必含 commentary（100-200 字深度解析）
6. **头条+趋势**: 额外一次 AI 调用，生成 TOP3 头条（含 300-500 字深度解读）+ TL;DR + 5 趋势分析
7. **股市数据**: 新浪 API（GBK 编码，`TextDecoder('gbk')` 解码）
8. **天气**: open-meteo
9. **完整性检查**: GOOD(40+条) / DEGRADED(20-39条) / LOW(<20条)
10. **降级机制**: AI 失败 → 降级到纯热榜数据（`fetch-cn-news.js` 静态模式）

**命令行**:

```bash
node fetch-news-ai.js --period=evening --output=data/evening-latest.json
ENABLED_SECTIONS=ai,finance,auto node fetch-news-ai.js --period=morning
```

### 协议自动识别

**Anthropic 协议**（`useAnthropicFormat: true`）：
```javascript
POST /v1/messages
Headers: x-api-key + anthropic-version
Body: { model, max_tokens, temperature, system, messages }
```

**Google Gemini 协议**（`useGoogleFormat: true`）：
```javascript
POST /v1beta/models/{model}:generateContent?key={api_key}
Body: { contents, generationConfig }
```

**百度文心一言协议**（`useBaiduFormat: true`）：
```javascript
POST /rpc/2.0/ai_custom/v1/wenxinworkshop/chat
Body: { model, messages, stream: false }
```

其余全部使用 **OpenAI 兼容协议**：
```javascript
POST /v1/chat/completions
Headers: Authorization: Bearer {api_key}
Body: { model, messages, max_tokens, temperature }
```

## HTML 邮件规范

### 渲染特性

- **渐变头部**: 4 时段不同配色
- **TL;DR 速览**: 金色 CSS 渐变背景
- **股市数据**: 深色容器 + 红涨绿跌

## GitHub Actions 工作流

### 触发方式

```yaml
# 1. 手动触发（可选 period）
workflow_dispatch:
  inputs:
    period:
      options: [auto, morning, noon, afternoon, evening]

# 2. 定时触发（UTC 时间）
schedule:
  - cron: '0 22 * * *'  # 北京时间 06:00 早报
  - cron: '0 4 * * *'   # 北京时间 12:00 午报
  - cron: '30 9 * * *'  # 北京时间 17:30 傍晚速递
  - cron: '0 13 * * *'  # 北京时间 21:00 晚间总结

# 3. API 外部触发
repository_dispatch:
  types: [lumapost-send]
```

### 执行环境

- **Runner**: ubuntu-latest
- **Node.js**: 20
- **npm 缓存**: 基于 package-lock.json
- **Secrets**: 从 GitHub Secrets 读取
- **Artifacts**: 保留 7 天
- **失败处理**: AI 失败自动 fallback 到 fetch-cn-news.js
